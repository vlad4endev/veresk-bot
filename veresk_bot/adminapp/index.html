Telegram

Сначала API-ключи, затем номер: телефон → код → коннект для рассылок.

1. Ключи Telegram API

Один раз на my.telegram.org — дальше можно подключать любые номера.

Получите на my.telegram.org → API development tools.

2. Подключённые номера

Сессии продлеваются каждые 30 мин. Если коннект пропал — переподключите номер.

1. Телефон 2. Код 3. Коннект
Новый номер Telegram

Введите телефон в международном формате. Код придёт в Telegram или SMS.

Полный коннект установлен

Сессия авторизована — можно отправлять рассылки.

MAX

Личный номер — рассылки от имени аккаунта. Бот — анкета, чаты и fallback-рассылки.

1. Личный номер (рассылки)

Неофициальный вход в MAX как пользователь: телефон → код из SMS → рассылки от вашего имени. Нужен RU IP на сервере.

1. Телефон 2. Код 3. Коннект
Новый номер MAX

Введите телефон в формате +79001234567. Код придёт в SMS / приложение MAX.

MAX-аккаунт подключён

Сессия сохранена — рассылки пойдут от имени этого номера.

Риск: неофициальный API — аккаунт могут ограничить. Лучше отдельный номер, не основной.

2. Токен бота

Создайте бота у @MasterBot в MAX → скопируйте токен → сохраните здесь. Нужен для анкеты и чатов; также fallback, если личного номера нет.

После сохранения сервис max_bot подхватит токен сам (или из .env). «Убрать» вернёт значение из .env.

3. Realtime (webhook)

Max сам присылает новые сообщения на ваш сервер — чаты в админке обновляются сразу. Нужен публичный HTTPS (порт 443).

Max будет слать его в заголовке X-Max-Bot-Api-Secret. Оставьте пустым, чтобы не менять уже сохранённый.

Пока webhook включён, long polling у сервиса max_bot не работает — так устроен Max API. Без webhook чаты тоже работают, но с задержкой опроса.

4. Уведомления флористу

Куда в MAX слать готовые анкеты. Пусто — только в Telegram (если задан) или никуда.

ID чата можно взять из логов бота или переписки с ботом-помощником Max.

Что дальше

Напишите боту /start из MAX — пойдёт та же анкета, что в Telegram. Диалог появится в Чаты → MAX.
